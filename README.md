# Open Roadway Assets

Open roadway assets

[/jrsignals-v2](./jrsignals-v2) - Contains meshes of JRSignals V2.

[/jrsignals-v3](./jrsignals-v3) - Contains the draft of JRSignals V3.

[/variable-speed-limit](./variable-speed-limit) - Contains the planned Illinois variable speed limit gantry.

[/lane-control](./lane-control) - Contains the Illinois lane control gantry.

[/blinking-chevron](./blinking-chevron) - Contains the blinking chevron sign.

Note that none of these are scripted at the moment.
